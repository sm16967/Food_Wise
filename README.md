# Food_Wise
 FoodWise – A smart food inventory and management web application that helps users track food expiration dates, manage grocery lists, learn proper food storage techniques, monitor food waste, and reduce unnecessary spending. Built with HTML, CSS, and JavaScript.


Problem

Food waste often happens because people forget expiration dates, purchase unnecessary items, store food improperly, or fail to keep track of what they already have. This leads to unnecessary food waste and financial losses.

Solution

FoodWise provides a simple platform to manage household food efficiently, make smarter shopping decisions, and encourage responsible food consumption.

Key Features

- Dashboard: View food inventory, expiration status, and waste statistics.
- My Inventory: Add, update, and manage food items.
- Expiration Tracker: Monitor expiration dates with visual status indicators.
- Storage Guide: Get useful food storage recommendations.
- Shopping List: Plan purchases and manage shopping items.
- Food Waste Tracker: Record wasted food and calculate its financial value.
- Dark and Light Mode: Switch between different interface themes.
- Responsive Design: Works on desktop and mobile devices.

Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SVG Icons

How It Works

1. Add food items with their quantity, price, and expiration date.
2. Monitor food status through the dashboard.
3. Check expiration dates and prioritize food consumption.
4. Create shopping lists to avoid unnecessary purchases.
5. Record wasted food and monitor financial losses.

Installation and Usage

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start managing your food inventory.

No additional software installation is required.

Data Storage

FoodWise uses browser LocalStorage to save inventory, shopping lists, and waste records.

Data is stored locally in the browser and is not automatically synchronized across devices or accounts. Clearing browser data may remove saved information.
